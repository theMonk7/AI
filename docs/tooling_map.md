# In-Demand Tooling Map (Mostly Free/Open Source)

## Core AI Application Stack
- Python 3.11+
- FastAPI
- Pydantic
- pytest

## Agent and LLM Orchestration
- LangChain
- LangGraph
- LiteLLM (optional router)

## Retrieval and Storage
- FAISS (local)
- Qdrant (OSS vector DB)
- PostgreSQL
- Redis

## Automation and Workflow
- n8n (primary low-code automation)
- Apache Airflow (batch DAG orchestration)
- Prefect OSS (Python-native orchestration)
- Node-RED (visual automation alternative)

## Observability and Evaluation
- OpenTelemetry
- Langfuse (OSS option)
- RAGAS or custom eval harnesses

## DevOps and Runtime
- Docker
- Docker Compose
- GitHub Actions

## Optional Paid Awareness
- Make
- Zapier

These are popular in the market, but this course emphasizes open-source-first learning and local reproducibility.
