# Glossary

- Agent: LLM-driven runtime that plans, calls tools, and iterates toward goals.
- Workflow: Deterministic orchestration of steps and states.
- Tool calling: Letting the model invoke functions with structured args.
- RAG: Retrieval augmented generation using external knowledge at inference time.
- Hybrid retrieval: combining dense and sparse retrieval.
- Reranking: scoring retrieved chunks for final relevance ordering.
- Idempotency: repeated execution yields safe non-duplicated results.
- Eval harness: repeatable measurement framework for quality, safety, and latency.
