# Project Standards

## Definition of done per week
1. Required coding labs completed.
2. Tests passing for the week scope.
3. Reflection notes recorded.
4. Measurable output saved in progress tracker.

## Engineering quality bar
- Type hints and clean module boundaries.
- Basic tests for critical functions.
- Logging for non-trivial flows.
- Retry, timeout, and failure handling where relevant.

## Documentation bar
- Each mini project has README, run commands, and known limitations.
