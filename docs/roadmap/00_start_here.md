# Start Here: Agentic AI Mastery Roadmap

## Purpose
This folder provides complete session-resumable learning context so any future agent session can continue exactly where you left off.

## Read order each session
1. roadmap_state.md (source of truth — active week + next action)
2. master_roadmap.md (full 24-week plan + phase map)
3. progress_tracker.md (completed tasks and evidence)
4. weeks/week-XX/README.md or weeks/week-XX.md (current week plan)
5. resources/tool_catalog.md (tool references)

## Folder map
- phases/: phase goals and competencies
- weeks/: detailed week-by-week lesson plans and outputs
- resources/: tool catalog, glossary, and project standards
- roadmap_state.md: active week and next action
- progress_tracker.md: evidence-based progress log

## Rule
Do not skip the checkpoint tasks in each week file. You can move to the next week only after satisfying required evidence.
