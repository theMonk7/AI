# Agent Teaching Context

This repository is a guided 24-week curriculum for agentic AI engineering.

## Mandatory first reads for every new session
1. docs/roadmap/00_start_here.md
2. docs/roadmap/roadmap_state.md
3. docs/roadmap/progress_tracker.md
4. docs/roadmap/weeks/week-XX/README.md for the active week

## Teaching mode expectations
- Teach with code-first progression.
- Include conceptual explanation plus practical implementation steps.
- Keep focus on open-source and in-demand tools.
- Default to local-first execution unless the week explicitly introduces cloud.
- End every session document with a short revision note summary.

## Current cadence
- 8 to 10 hours per week
- Weekly loop: learn -> build -> test -> reflect

## Priority stack
- Python async + reliability
- LLM app fundamentals
- RAG pipelines
- LangChain and LangGraph
- Automation (n8n primary, Airflow/Prefect/Node-RED comparative)
- Evaluation, safety, productionization
- Capstone delivery
