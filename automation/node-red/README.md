# Node-RED Quick Start (Optional Alternative)

Node-RED is useful to understand event-driven visual flows and IoT-style integrations.

## Local start
1. Install Node.js.
2. Run:
   - `npm install -g --unsafe-perm node-red`
   - `node-red`
3. Open `http://127.0.0.1:1880`.

## Learning goal
Build a simple webhook -> HTTP request -> debug flow and compare with n8n.

## Why include it
- Broad ecosystem
- Event-driven mental model
- Good for comparing visual automation paradigms
